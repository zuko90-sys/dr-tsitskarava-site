# Набор стилей «в духе ВкусВилла»

Переносимый набор из прототипа курьерского приложения: токены, компоненты,
шрифты, иконки. Подключается к любому вебу без сборщика.

**Не официальный брендбук.** Из настоящего фирменного стиля взяты два цвета
с публичной страницы vkusvill.ru/brand: зелёный `#2DBE64` и ягодный `#D7144B`.
Логотип не входит. Шрифты — свободная замена (настоящий шрифт ВкусВилла
проприетарный): Unbounded + Golos Text, лицензия OFL, отдаются Google Fonts.

## Подключение

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Unbounded:wght@400;600;800&family=Golos+Text:wght@400;500;600;700&display=swap">
<link rel="stylesheet" href="tokens.css">
<link rel="stylesheet" href="icons.css">
<link rel="stylesheet" href="ui.css">
```

Порядок важен: токены раньше компонентов. `fonts.css` — запасной вариант
через `@import`, если нет доступа к `<head>`.

## Темы

Светлая — по умолчанию. Тёмная включается сама от системной настройки
пользователя, принудительно — атрибутом на корне:

```html
<html data-theme="dark">   <!-- всегда тёмная -->
<html data-theme="light">  <!-- всегда светлая, сильнее системной -->
<html>                     <!-- по системной настройке -->
```

Все цвета — CSS-переменные в `tokens.css`. Переопределите токен —
компоненты перекрасятся сами; в компонентах ни одного зашитого цвета.

## Компоненты (ui.css)

| Класс | Что это |
|---|---|
| `.card` `.card--green` `.card--warn` `.card--flat` | карточка и её тона |
| `.card__label` `.card__title` `.card__note` | подпись-капс, заголовок, примечание |
| `.live` | строка статуса с пульсирующей точкой |
| `.ring` | кольцо прогресса (SVG, `--dash` 0–283, класс `is-drawn` запускает анимацию) |
| `.bar` | полоса прогресса (`--pct`, класс `is-drawn`) |
| `.stat` | строка «ключ …… значение» с точечной линией |
| `.levels` `.level` | вертикальный путь уровней |
| `.badges` `.badge` | сетка знаков-ачивок |
| `.note-chip` (`--warn`) | подсказка с иконкой |
| `.rank` (`.me`) | строка рейтинга |
| `.team-row` | строка участника команды |
| `.unlock` (`--warn` `--off`) | плашка доступа с замком |
| `.slot` `.slot__pill` (`--mine` `--muted`) | слот расписания и его кнопка |
| `.check` `.check__i` | чек-лист с отмечаемыми пунктами |
| `.mentor` | карточка человека с кнопкой связи |
| `.fix` | нумерованный список «что подтянуть» |
| `.feed` | лента событий (`--win` `--warn` — вехи) |
| `.nudge` | «скоро»: цель с прогрессом |
| `.sheet` `.dispute` | нижняя шторка и её строки |
| `.toast` | всплывающее сообщение |
| `.ev` (`--minus` `--ghost`) | чип-кнопка |
| `.tabbar` `.tab` | нижняя навигация |
| `.num` | табличные цифры |

Классы только для демо-стенда — `.deck` `.stamp` `.profiles` `.stage`
`.sim` `.hint` и рамка телефона `.phone`/`.app` — можно удалить.

## Иконки

22 контурные иконки, цвет из `currentColor`:

```html
<svg class="icon"><use href="icons.svg#i-shield"/></svg>
```

С `file://` внешний спрайт в Chrome не работает — тогда вставьте содержимое
`icons.svg` в начало `<body>` и ссылайтесь `href="#i-shield"`
(так сделано в `demo.html`).

## Демо

Откройте `demo.html` — все компоненты в обеих темах, переключатель сверху.
