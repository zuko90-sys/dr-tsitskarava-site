# Мультяшные вставки: как писать сцены

Вставка — это SVG 1080×1920, который `render.js` снимает покадрово в Chromium. Вне вставок кадр прозрачный, на «ирисе» видна часть видео под ним. Сцены детерминированы: `update(u)` полностью выставляет состояние по времени, без CSS-анимаций и `setTimeout`. Поэтому любой кадр можно отрендерить в любом порядке.

## Устройство

- `anim.html` — каркас: фон с градиентом и «пузырями», клип-«ирис», группа `#scenes`. Подключает `lib.js` и `scenes.js`.
- `lib.js` — помощники и персонажи (ниже).
- `scenes.js` — сцены проекта и в конце `setupTimeline([{t0, t1, sc}, …])`. Образец: `scenes.example.js`.

Сцена — это IIFE, которая создаёт элементы один раз и возвращает `{g, labels, update(u, t)}`:

```js
const S1 = (() => {
  const g = el('g', {}, root);                 // root = #scenes
  const st = Stomach(g, 's1');                 // id уникален на сцену (clipPath)
  const b = Bacterium(st.kids);                // «дети» желудка двигаются вместе с ним
  const lb = Label(g, 'ГАСТРИТ', {fill: RED});
  return {
    g, labels: [lb],                           // labels: их ширину подгоняет fitLabels()
    update(u) {                                // u — секунды от начала вставки
      st.set({x: 540, y: 960, s: .95 * E.outBack(prog(u, .05, .5)), inflam: E.inOut(prog(u, 1, 2.4)),
              mood: u < 2 ? 'worried' : 'pain', t: u});
      b.set({x: 115, y: 150, s: .7 * E.outElastic(prog(u, .4, .95)), t: u});
      lb.set({x: 280, y: 700, s: E.outBack(prog(u, 2.2, 2.55)), r: -6});
    }
  };
})();
setupTimeline([{t0: 6.03, t1: 14.43, sc: S1}]);
```

## Помощники

- `el(tag, attrs, parent)` — создать SVG-элемент.
- `prog(t, a, b)` — 0…1 на отрезке.
- `lerp(a, b, x)`, `clamp`.
- `mix('#hex1', '#hex2', x)` — смесь цветов.
- `tf(x, y, s, r)` — строка transform.
- `blink(t, period, offset)` — моргание.
- Сглаживания `E.outBack` (выскок с перелётом — для появлений), `E.outElastic` (пружина — для бактерий), `E.inOut` (переезды), `E.outCubic`, `E.inCubic` (уходы).
- Цвета: `INK #16362B` (обводки), `MINT`, `GREEN`, `RED`, `LIME`.

## Персонажи (`lib.js`)

| Конструктор | `set({...})` | Заметки |
|---|---|---|
| `Face(parent, {lx, rx, y, r, mouthY, w})` | `.set(mood, t, look[x,y], blinkOn)` | настроения: happy, neutral, worried, pain (глаза >_<), sad, tired (закрытые), sly (хитрый) |
| `Stomach(parent, id)` | `x, y, s, r, inflam 0…1, mood, t, look, ulcerS 0…1, pain 0…1` | Анатомически: дно справа от зрителя, привратник слева (внутри `scale(-1 1)`). `.kids` — группа для бактерий и капель в локальных координатах (тело ≈ x −270…420, y −340…250). Язва в (150, 135) |
| `Bacterium(parent)` | `x, y, s, r, t, mood, look, vis` | S-образная H. pylori с пучком жгутиков, извивается от `t`. Длина ≈ 300 px при s=1, обычно s 0.6–0.7 |
| `FeBall(parent)` | `x, y, s, o, r` | шарик железа «Fe» |
| `RBC(parent)` | `x, y, s, pale 0…1, t, o, mood` | эритроцит; при `pale→1` бледнеет, уменьшается до 80% и засыпает (z z) — так выглядит железодефицит |
| `Label(parent, text, {fill, color, size, padX, h})` | `x, y, s, r, o` | ярлык-таблетка; появление через `E.outBack`, лёгкий наклон −4…−8° |
| `Burst(parent, color)` | `.set(x, y, p, R)` | лучики на появление (p 0→1 за 0.3–0.4 с) |
| `Drop(parent)` | `x, y, s, o` | капля крови |

В `scenes.example.js` ещё есть «батарейка» запасов железа (сцена D) и чек-лист с галочками через `stroke-dashoffset` (сцена E). Их можно брать как образцы, если нужен уровень или список.

## Новые персонажи

Держи общий стиль:
- обводка `INK` 6–9 px со скруглёнными концами;
- плоские заливки, 2–3 цвета на персонажа, блик белым с прозрачностью .3–.45;
- глаза — белые с тёмным зрачком и бликом (бери `Face`), румянец `#F27B86` с прозрачностью .45.

Тело рисуй вокруг (0, 0), чтобы `tf(x, y, s, r)` работал предсказуемо. Персонаж с лицом сразу «оживает»: дай ему настроение под смысл фразы.

## Раскладка и тайминг

- Главное держи в y 540–1250, по центру x 540. Выше лежат плашки (230–520), ниже — титры (1270–1450). Ярлыки ставь в свободный угол рядом с персонажем, обычно в вогнутость желудка слева сверху (~280, 690).
- События привязывай к словам. Времена слов в ролике лежат в `in/words_cut.json`: ярлык выскакивает на слове, переход сцены — на смене мысли.
- Одна вставка = 1–2 «бита». Второй бит — переезд и уменьшение главного персонажа (`E.inOut` за ~0.5 с) и новые герои под ним.
- Ирис: 0.32 с в начале и в конце вставки. Сцене нужно 0.05–0.5 с на появление главного героя.

## Проверка

```bash
node anim/render.js <проект>/anim stills 7.9,11.2,13.9
ffmpeg -i s_7.9.png -i s_11.2.png -i s_13.9.png -filter_complex "hstack=inputs=3,scale=1800:-1" sheet.png
```

Посмотри лист (Read) и проверь:
- ничего не залезает в зоны плашек и титров;
- ярлыки читаются;
- анатомия и смысл верные;
- персонажи не перекрывают друг другу лица.

Потом рендери все кадры: `frames <кадров> 30`.
