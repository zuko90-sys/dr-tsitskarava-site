# Файлы проекта рилса

```
<проект>/
├── reel.json          конфиг сборки
├── captions.txt       титры (экраны)
├── sfx.json           звуки (если есть вставки)
├── in/                raw-видео, audio.wav, words.json, words_cut.json, transcript.md, sfx.wav
├── anim/              anim.html, lib.js, render.js, scenes.js, stills/, frames/
├── preview/           кадры из make_reel.py --preview
└── out/               reel.mp4, reel.srt, reel.ass
```

Рабочий образец всех трёх файлов: `assets/example/`.

## reel.json

**Все времена — в секундах готового ролика (после обрезки), кроме `cut` и `end`:** эти два — точки в исходнике.

| Поле | Что это |
|---|---|
| `src` | исходное видео относительно папки проекта. Любое разрешение: приводится к 1080×1920 (scale+crop) |
| `cut`, `end` | с какой и по какую секунду исходника брать |
| `fps` | 30 по умолчанию |
| `captions` | файл титров, по умолчанию `captions.txt` |
| `zoom.anchor` | точка лица в кадре 1080×1920: при приближении она остаётся на месте |
| `zoom.segments` | `[[начало, масштаб], …]`, первый всегда `[0, …]`. Чередуй 1.0 и 1.12. Склейки ставь в паузы речи, а при вставках — внутрь вставок |
| `title` | хук сверху: `from`, `to`, `text`, `sub`, `y` (250), `sub_y` (500) |
| `plaques` | `[{from, to, label, text}]`: метка («ПРИЧИНА 1») и текст плашки разделов |
| `inserts` | `[[t0, t1], …]`: интервалы анимационных вставок, **те же, что в `setupTimeline` в scenes.js**. Нужны, чтобы убрать тёмную подложку титров поверх анимации |
| `anim_frames` | `anim/frames/%05d.png`, или убери поле, если вставок нет |
| `sfx`, `sfx_gain_db` | `in/sfx.wav` и усиление дорожки звуков (+6 дБ) |
| `style` | `cap_size` (76), `cap_outline` (5), `cap_margin` (500 = низ титров на y 1420), `soft` (true), `head_margin` (370 = верх плашки) |
| `out` | `out/reel.mp4` |

В текстах `title` и `plaques` действует та же разметка, что в титрах: `/` — перенос строки, `*…*` — мятный акцент.

## captions.txt

```
// комментарий
Если у вас есть / *анемия*,
то вам обязательно / нужно обратиться
*хеликобактер-* / *ассоциированная*
```

- Одна строка — один экран. Экран держится до начала следующего, если пауза между ними меньше 1,5 с, а после конца фразы остаётся ещё 0,35 с.
- Текст сопоставляется с распознанными словами по похожести. Пунктуация, регистр и ё/е не мешают. Слова через дефис сравниваются по частям.
- Латиница сравнивается через словарь транслитерации `LAT` в `build_subs.py` (helicobacter → хеликобактер, pylori → пилори, C → ц). Если в титрах новые латинские термины, допиши их туда. Иначе выравнивание растянет время на соседей, а в отчёте фраза будет < 100%.
- Строки `!TITLE верх | низ` и `#1 Заголовок` поддерживаются для режима «говорят строго по сценарию»: тогда заголовки разделов привязываются к голосу. В режиме живой речи заголовок и плашки задаются в `reel.json`.

## sfx.json

```json
[[6.03, "whoosh", -24], [7.58, "boing", -22], [10.83, "stamp", -19], [36.52, "ding:1320", -24]]
```

`[время в ролике, звук, дБ]`. Доступные звуки:
- `whoosh` (переход-«ирис»), `whoosh:soft`;
- `pop` (появление), `stamp` (ярлык), `boing` (бактерия выскочила);
- `knock`, `drip`, `tick`, `ding[:Гц]`, `drain[:сек]`.

Ориентиры громкости: переходы −24…−29, появления −21…−24, ярлыки −19…−21, капли −23…−27.
